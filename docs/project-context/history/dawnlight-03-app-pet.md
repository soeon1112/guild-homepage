## 1. 앱 초기 설정 및 Firebase 연동

### 1-1. iOS Firebase 설정 추가 [앱]
- **요약**: app.json에 iOS용 GoogleService-Info.plist 경로 추가 + APK 재빌드
- **파일**: `app.json`, `GoogleService-Info.plist`
- **배경**: Android용 google-services.json은 있었지만 iOS용 설정이 누락돼 있었음

### 1-2. FCM V1 서비스 계정 키 등록 [앱]
- **요약**: Expo에 FCM V1 서비스 계정 키(Google Service Account Key) 업로드
- **파일**: `dawnlight-guild-3181d3388f9f.json` (서비스 계정 키)
- **배경**: 푸시 토큰은 발급됐지만 알림이 안 왔음. Expo가 FCM에 접근할 키가 없었음
- **오류 해결**: `InvalidCredentials` → FCM V1 키 등록으로 해결

### 1-3. 최신현황(activity) 알림 트리거 수정 [공통]
- **요약**: Cloud Functions의 최신현황 트리거 경로를 실제 Firestore 경로와 일치시킴
- **파일**: `functions/src/triggers/latest.ts`, `functions/src/index.ts`
- **배경**: 트리거가 `members/{id}`를 감시했지만 실제 데이터는 `activity/{id}`에 저장됨
- **오류 해결**: 옛 함수(`onMemberStatusChanged`) 삭제 + 신규 함수(`onActivityCreated`) 배포

## 2. 아바타 시스템 — Firebase Storage 전환

### 2-1. 아바타 이미지 Firebase Storage 전환 [공통]
- **요약**: 로컬 폴더의 아바타 이미지를 전부 Firebase Storage에 업로드하고, 홈페이지+앱 코드를 URL 참조 방식으로 변경
- **파일**: `scripts/upload-avatars.mjs`, `src/lib/avatarAssets.ts` (홈페이지), `src/avatar-assets.ts` (앱), Avatar/shop 컴포넌트
- **배경**: 이미지 추가할 때마다 앱 재빌드가 필요한 구조를 개선. Storage URL로 변경하면 이미지만 교체하면 됨

### 2-2. 캐시 정책 변경 (1년 → 1시간) [공통]
- **요약**: Firebase Storage 이미지 캐시를 `max-age=31536000`에서 `max-age=3600`으로 변경
- **파일**: `scripts/upload-avatars.mjs`
- **배경**: 이미지 교체해도 브라우저 캐시 때문에 반영이 안 되는 문제

### 2-3. 캐시 버스팅 (배포 시점 타임스탬프) [공통]
- **요약**: 아바타 URL에 배포 시점 타임스탬프를 쿼리스트링으로 추가
- **파일**: `avatarUrl()`, `partUrl()` 함수
- **배경**: 캐시 정책 변경 후에도 일부 이미지가 안 바뀌는 문제의 근본 해결

## 14. 펫 성능 최적화 (iOS)

### 14-1. iOS 스크롤 지연 해결 [앱]
- **요약**: Pressable 두 겹 안에 ScrollView가 갇혀서 iOS gesture-conflict 발생 → backdrop을 panel의 sibling으로 분리
- **파일**: FloatingPet.tsx 패널 JSX 구조
- **배경**: 진단 인스트루먼트로 T0~T7 타이밍 측정. T7(onScrollBeginDrag)이 영영 안 발화된 것 확인
- **오류 해결**: Pressable 2겹 → backdrop/panel sibling 구조로 변경
- **⚠️ 함정 기록**: iOS는 Pressable 두 겹 안에 ScrollView 넣지 말 것 (gesture conflict)

### 14-2. iOS 알 움직임 버벅거림 해결 [앱]
- **요약**: PetRoom이 1초마다 리렌더(인라인 onSceneEnd, behavior 새 객체, egg blink 토글) → SVG layer invalidation
- **파일**: FloatingPet.tsx (useCallback), PetRoom.tsx (useMemo, blink skip)
- **수정 내용**: onSceneEnd → useCallback, behavior → useMemo, egg blink skip, 펫 SVG → useMemo 캐시

### 14-3. iOS borderRadius + overflow:hidden 분리 [앱]

- **⚠️ 함정 기록**: iOS는 `borderRadius + overflow:hidden` 안에 애니메이션 자식 넣지 말 것 → layer invalidation
