## 3. 채팅창 사진 큰 보기 수정

### 3-1. 증상
- 홈페이지 PC/모바일: 채팅창 안에서만 작게 보임
- 앱 (안드/iOS): 사진 클릭해도 아무 동작 X

### 3-2. 진단 결과 (진짜 원인)
- 홈페이지: CommentImageView에 라이트박스 코드 이미 있었음
- **진짜 원인**: framer-motion이 채팅 패널에 `transform: scale()`을 걸어서 그 자손의 `position: fixed`가 viewport 기준이 아니라 패널 박스 기준으로 잡힘 → 채팅창 안에 작게 클립됨
- **해결**: `createPortal(lightbox, document.body)`로 transform context escape

### 3-3. 변경 파일
- 홈페이지: 
  - `app/components/CommentImage.tsx` (+27/-22): createPortal로 document.body에 portal
  - `app/globals.css` (+3/-1): 라이트박스 z-index 200 → 1000
- 앱: 
  - `src/components/FloatingChat.tsx` (+~75줄): Pressable + Modal + expo-image contentFit="contain"
  - 우상단 X 버튼 + 배경 어디든 탭하면 닫힘

### 3-4. gif/mp4 처리
- gif: 홈피 `<img>`(자동 애니메이션), 앱 expo-image (gif 자동 디코드) → 같은 라이트박스로 ✓
- mp4: 인라인 컨트롤의 풀스크린 버튼 동작 (변경 없음)

### 3-5. 핵심 학습
- **transform: scale() + position: fixed 함정**: 부모에 transform 걸려있으면 자식 fixed가 viewport 기준으로 안 잡힘. 다음에 비슷한 증상 나오면 transform 걸려있는지 먼저 확인.
- createPortal(document.body)로 escape 가능

### 3-6. 적용 안 한 부분 (스코프)
- 좌우 스와이프로 채팅 안 다른 사진 넘기기 → 단일 이미지 뷰어만 구현
- 핀치 줌 (앱) → contentFit="contain"까지만, 100% 원본 픽셀 보기는 추후

## 4. 푸시 알림 중복 버그 수정

### 4-1. 증상
- 모든 종류 푸시 알림이 두 번씩 옴 (댓글, 채팅, 방명록, 사진첩, 펫 등 전부)
- iOS에서 확인 (안드는 태블릿이라 확인 불가)
- 한 폰에 같은 알림이 두 번 도착

### 4-2. 진단 결과
- 트리거 중복 ❌ — 18개 deployed 함수 모두 source와 1:1 매칭, 한 이벤트당 1번만 실행
- 클라이언트 listener 중복 ❌ — setNotificationHandler는 모듈 로드 시 1회만 호출
- 홈피 functions 중복 ❌ — 홈피에 functions 폴더 자체 없음
- **토큰 중복 ✅ — 진짜 원인**:
  - `ExponentPushToken[ZyF2BLBK8oqX0WpkgC-E0H...`
    - users/언쏘 (updated 2026-05-02)
    - users/테스트 (updated 2026-04-29)
  - 같은 폰에서 테스트 계정으로 한 번 로그인했던 흔적이 안 지워짐
  - 클라이언트 `registerDeviceForPush`는 현재 닉네임 doc에만 setDoc하고 다른 doc에서 토큰 회수 안 함 (security rules로 불가능)
  - Broadcast 트리거가 두 user 모두 잡아서 같은 토큰에 2번 발송

### 4-3. 수정
- **서버 코드 패치** (`functions/src/lib/recipients.ts`):
  - `getRecipientsForCategory`에 token 기준 dedupe 추가
  - 정렬: `pushTokenUpdatedAt` 최신 우선 (가장 최근 등록한 계정의 settings 존중)
  - 동일 토큰의 다른 doc은 drop + warn 로그
  - `getRecipientByNickname`은 단일 doc만 보므로 영향 없음 (myspace 류 owner 알림은 원래 정상)
- **데이터 위생 (1회)**:
  - users/테스트.pushToken → null (백업: `guild-homepage/backups/stale-push-2026-05-03/users__테스트.json`)
  - 11명 candidates → 중복 0건

### 4-4. 영구 방지책
- dedupe로 자동 처리 — 누가 다시 같은 폰에 다른 계정 로그인해도 broadcast는 최신 등록자에게만 1번
- myspace 류 owner 알림은 단일 recipient라 영향 없음

### 4-5. 진단 도구 (재사용 가능)
- `guild-homepage/scripts/dump-push-state.mjs <닉네임>` — 토큰 상태 dump
- `guild-homepage/scripts/scrub-stale-push-tokens.mjs` — 다른 사람도 정리 시 사용 (dry-run → --apply)

### 4-6. 핵심 학습
- 추측 5번 vs 진단 1번. 작업 일지 chat5 WebView 404와 같은 패턴.
- "FCM 토큰이 한 번 더 등록됐을 가능성" 가설이 실제 원인이었음 (재빌드 + 다른 계정 로그인이 원인)

## 7. 낚시 게임 변경

### 7-1. 채팅 이력 보기 기능
- **위치**: 게임 viewport 우상단 (낮밤 디버그 자리)

- **닫기**: X 버튼 X, 아이콘 다시 누르면 토글
- **메시지**: Firestore `fishing_chat` 컬렉션 영구 저장 (최근 100~200개), 새로고침/재접속해도 이력 유지
- **자동 정리**: Cloud Function으로 메시지 수 200개 초과 시 가장 오래된 것 삭제 (activity 컬렉션 패턴)
- **게임 조작 가능**: 창 열린 상태에서도 이동/낚시/채팅 가능
- **첫 시도 후 전체 공개**: canDebugFishing 제한 제거

### 7-2. 낮/밤 디버그 토글 제거
- 우상단 🌗 ☀ 🌙 토글 버튼 + 디버그 기능 자체 제거
- 자연 시간 기반 낮/밤 사이클 (낮 30분/밤 5분)은 그대로 유지

- 도감/인벤토리 등 다른 곳에도 일관 적용

## 9. 키보드/스크롤 처리 (작업 진행 중)

### 9-1. 홈페이지 모바일 (적용 완료) ✓
- 모달 안 입력: 펫/채팅 아이콘 숨김 + 모달이 키보드 위로 자연스럽게 올라감
- 페이지 직접 입력 (방명록, 게시판, 메인 한마디 등): 펫/채팅 아이콘 자기 자리, 입력란이 키보드 위 보이는 영역으로 자동 스크롤

### 9-2. 앱 (적용 누락) ⚠️
- 펫/채팅 아이콘 숨김만 됐고 입력란이 키보드에 가려지는 문제 그대로
- **수정 필요**: 케이스 A (모달 안 입력)는 KeyboardAvoidingView (iOS padding, Android height), 케이스 B (페이지 직접 입력)는 KeyboardAwareScrollView 또는 수동 ScrollView 처리
- 라이브러리 추가 필요하면 빌드 (OTA 안 됨) → 길마 결정 필요

### 9-3. 홈페이지 모바일 가로 스크롤 문제
- 명령 짜줬으나 보냈는지 미확인
- root에 `overflow-x: hidden`은 안전망, 진짜 원인(어느 요소가 폭 넘기는지) 찾아 max-width 100% 적용이 정답
- viewport meta 태그, 긴 영문 단어 줄바꿈, 이미지 max-width, flex 자식 min-width 0 등 점검

## 핵심 학습 (이번 chat 종합)

### 1. "추측 말고 진단부터" 재확인
- 푸시 중복 버그 = 토큰 dump 후 진짜 원인 발견
- 채팅 사진 큰 보기 = framer-motion + position fixed 함정 발견
- 둘 다 추측으로 접근했으면 또 헛수고했을 것

### 2. "데이터 변경 전 백업" 원칙
- 푸시 토큰 정리 전 `backups/stale-push-2026-05-03/` 폴더 만들어 dump 먼저
- 길드원 정리 시 dump → 확인 후 삭제
- 되돌릴 수 없는 작업은 반드시 백업

### 3. "자동 배포 정책 = 함정 회피"
- 홈페이지 + 앱 양쪽 누락 함정 자동 회피
- 길마가 매번 명시 안 해도 일관된 배포

### 4. "비전공자도 진짜 만들 수 있는 시대"
- 코드 1년 전엔 비전공자가 절대 못 만들었던 규모
- Claude Code = AI가 직접 코드 보고/수정/실행하는 도구
- 길마가 "이건 좀 이상한데?" 직감 가지면 진짜 버그 발견 가능 (STAR 알고리즘 + 푸시 중복 둘 다 길마 직감 시작)

### 5. "5번 시도한 이력은 작업 일지에 남겨야 한다"
- 같은 함정 또 빠지지 않게
- 디버그 박스 패턴, framer-motion + fixed 함정, 토큰 중복 패턴 등 다 메모
