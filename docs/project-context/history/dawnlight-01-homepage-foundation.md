# 새벽빛 길드 — 01. 홈페이지 첫 구축 (chat1)

> **작업 기간**: 2026-03-31 ~ 2026-04-22
> **프로젝트**: 새벽빛(Dawnlight) 마비노기 모바일 길드 홈페이지
> **기술 스택**: Next.js + Firebase/Firestore + Tailwind + Vercel
> **작업 방식**: Claude(claude.ai) 프롬프트 가이드 → Claude Code 실행

> 참고: 이 시기 디자인은 **학원/엠블럼 컨셉**이었음. 이후 chat2에서 **우주/별자리 컨셉**으로 전면 리뉴얼됨. 학원 컨셉 작업 과정 일부는 우주 테마로 대체됐으니 참고만.

## Phase 1: 메인 페이지 구축

### 1-2. 메뉴 순서 및 디자인 수정
- **한 줄 요약**: 공지사항 삭제, 버튼 순서 변경(길드규칙→일정→길드원소개→투력→앨범→길드추억), 디자인 귀엽게
- **관련 파일**: `src/app/page.tsx`

### 1-3. 커스텀 이미지 적용 (배경 + 버튼 + 로고)
- **한 줄 요약**: AI 생성 이미지로 배경(background.png), 메뉴 버튼 6개, 로고(logo.png) 교체
- **관련 파일**: `src/app/page.tsx`, `public/images/` (background.png, logo.png, 6개 메뉴 이미지)
- **배경**: 처음 새벽빛 컨셉 → 이후 학교 컨셉으로 전면 교체
- **오류 1**: 이미지에 filter/blur/opacity 적용되어 흐리게 나옴 → "절대 하면 안 되는 것" 목록 명시하여 해결
- **오류 2**: Next.js Image 컴포넌트에서 `?v=2` 쿼리스트링 에러 → 일반 `img` 태그로 교체
- **오류 3**: 버튼 이미지에 글자 포함 → 글자 없는 아이콘만 사용, 메뉴 이름은 코드로 표시

### 1-4. 버튼 호버 효과 수정 (투명 배경 네모 테두리 문제)
- **한 줄 요약**: 투명 PNG 버튼에 `box-shadow`가 네모 테두리 생성 → `filter: drop-shadow()`로 교체
- **관련 파일**: `src/app/page.tsx`
- **배경**: `drop-shadow`는 이미지의 실제 형태를 따라가므로 네모 테두리 안 생김

### 1-5. 글자색/외곽선 수정
- **한 줄 요약**: 메뉴명·헤더 "새벽빛" 텍스트 색상을 파란색(#4a90d9) + 흰색 외곽선으로 통일
- **관련 파일**: `src/app/page.tsx`
- **배경**: 보라색 → 금색 → 파란색으로 여러 번 변경, 최종 파란색 확정

### 1-6. Open Graph 메타데이터 설정
- **한 줄 요약**: 링크 공유 시 미리보기 이미지/제목 설정
- **관련 파일**: `src/app/layout.tsx`
- **오류**: 카카오톡 캐시 문제로 미리보기 안 바뀜 → 로고 파일명을 `guild-logo.png`로 변경 + 카카오 캐시 초기화

## 전반 수정사항 (전 작업 공통)

### 댓글/대댓글 통합
- 이미지 첨부: 카메라 아이콘 (input hidden), 입력칸 옆 40px
- 입력 레이아웃: [입력칸(flex-1)] [카메라(40px)] [등록(60px)] 가로 한 줄 (흔적 남기기는 카메라 없이)
- 대댓글 입력칸: 기본 숨김, "답글" 버튼 누르면 해당 댓글 아래에 나타남
- 대댓글 목록: 항상 펼침
- 댓글 삭제: 본인만 삭제 가능 (로그인 닉네임 === 작성자)
- 날짜 표시: 오늘이면 HH:MM, 아닌 날은 MM.DD만
- 줄바꿈 들여쓰기: 두 번째 줄부터 왼쪽 16px 들여쓰기 (닉네임 길이 무관)
- 댓글 수 표시: 대댓글 포함 카운트
- 이후 (chat4): 날짜 위치를 닉네임 옆 → 답글/삭제 버튼 옆으로 이동, 가로 한 줄 유지

### 스크롤/네비게이션
- 스크롤 위치 기억: 모든 페이지 sessionStorage 저장, 돌아가기 시 복원
- 돌아가기 버튼: `router.back()` 사용, 이전 페이지 없으면 메인으로
- 모달 배경 스크롤 방지: body overflow hidden

### 모바일 최적화
- 자동확대 방지: input/textarea 폰트 16px 이상 + viewport maximum-scale=1
- 로그인 버튼: 텍스트 축약 (출석완료→출석, 마이정보→MY) 한 줄 배치
- 사진 크게 보기: X 닫기 버튼 44px, 사진 바깥 위에 배치
