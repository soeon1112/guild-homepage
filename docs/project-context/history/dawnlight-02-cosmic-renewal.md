## Phase 0: 디자인 컨셉 확정 & v0.dev 프롬프트

### 0-1. v0.dev 역할 분담 확정
- **한 줄 요약**: v0.dev로 디자인 시안 만들고, Claude Code로 기존 프로젝트에 이식하는 워크플로우 확정
- **배경**: Claude Code만으로는 디자인 퀄리티 한계 → v0.dev로 비주얼 먼저, Claude Code로 기능 통합
- **결정 사항**:
  - v0 = 새 디자인 컨셉/레이아웃 (백지에서 창작)
  - Claude Code = 기존 코드에 이식 + Firebase 연결 + 기능 구현
  - Claude(claude.ai) = 프롬프트 작성 + 의사결정 가이드

### 0-2. 디자인 컨셉 확정: 우주/별자리 테마
- **한 줄 요약**: 4개 세계관 후보(소우주/요정숲/마법사공방/밤하늘캠프) 중 "작은 소우주 + 청보라 성운 + 별자리" 확정
- **배경**: 기존 "학원/귀족 엠블럼" 테마에서 탈피
- **확정 컬러 팔레트**:
  - 배경: #0B0821 → #1A0F3D 그라데이션
  - Deep purple #3D2E6B, Dawn violet #6B4BA8
  - Cosmic pink #D896C8, Stardust cream #FFE5C4
  - 포인트: #FFB5A7 (피치)
- **폰트**: Noto Serif KR (제목), Pretendard (본문)
- **효과**: 글래스모피즘, 별 입자 twinkle, 그라데이션 글로우

### 0-3. v0.dev 프롬프트 — 메인 페이지 작성
- **한 줄 요약**: 메인 페이지 전체 구조를 v0에 넣을 상세 프롬프트 작성
- **핵심 구성**: 헤더(sticky) → TodaySky(별자리+출석) → 별똥별 편지 → 성운의 속삭임(최신현황) → 별에게 한마디 → STAR OF THE DAY → 하단 네비 6탭

- 각 페이지별로 v0에 넣을 상세 프롬프트 작성. 결과물은 Phase 4~6에서 이식.
